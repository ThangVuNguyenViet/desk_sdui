# desk_sdui — Pattern matching (switch expressions + simple destructuring)

**Goal:** Support Dart 3 `switch` expressions and record destructuring in `@Screen` bodies. State-driven UI (`switch (state) { Loading() => ..., Loaded(:final data) => ... }`) is a very common pattern that today forces a registered VM method.

**Architecture:** Pure lowering — no new runtime machinery. Bucket 1.
- Switch expressions over literal values → chain of `ConditionalNode(CompareOpNode('==', scrut, lit), branch, else)`.
- Switch expressions over type patterns (`Loading()`, `Loaded(:final data)`) → chain of `ConditionalNode(IsTypeNode(scrut, 'TypeName'), branch, else)`. Requires new `IsTypeNode` (this plan adds it).
- Field-bound type patterns (`Loaded(:final data)`) wrap the matched branch in a `LetNode(name: 'data', value: MemberAccessNode(scrut, 'data'), body: branch)`. Requires `LetNode` (Feature 1) to be merged.
- Record destructuring (`final (a, b) = vm.pair;`) lowers to two `LetNode`s extracting `.$1` and `.$2`. Same dependency on Feature 1.

**Dependencies:** `LetNode` (Feature 1) must be merged for the binding cases. Pure-literal switch expressions work without LetNode but should still be in the same plan to avoid two passes.

**Tech stack:** existing IR + new `IsTypeNode`, lowerer, generator.

**Step 1 — Define the node** (near `IsNullCheckNode`):

```dart
/// Non-null type test: `receiver is TypeName`. Resolved by checking the
/// runtime type against a registered Dart type name. Type names are matched
/// by simple name string — payload generics are erased.
final class IsTypeNode extends ExpressionNode {
  const IsTypeNode({required this.receiver, required this.typeName});
  final IrNode receiver;
  final String typeName;

  @override
  bool operator ==(Object other) =>
      other is IsTypeNode &&
      other.receiver == receiver &&
      other.typeName == typeName;
  @override
  int get hashCode => Object.hash(receiver, typeName);
  @override
  String toString() => 'IsTypeNode($receiver is $typeName)';
}
```

```dart
final Map<String, bool Function(Object?)> _typeChecks = {};

/// Registers a predicate that returns true iff [value] is an instance of the
/// Dart type identified by [name]. Generated by codegen for sealed classes
/// referenced in @Screen bodies.
void registerTypeCheck(String name, bool Function(Object?) check) =>
    _typeChecks[name] = check;

bool checkType(String name, Object? value) {
  final pred = _typeChecks[name];
  if (pred == null) {
    throw StateError(
      'No type check registered for "$name". '
      'Sealed types used in switch expressions must be registered '
      'via the @Register annotation on the sealed parent.',
    );
  }
  return pred(value);
}
```

## Task 4 — Lowerer: switch expressions

**Files:**
- Modify: `packages/desk_sdui_generator/lib/src/screen_lowering/expression_lowerer.dart`

**Step 1 — Recognize `SwitchExpression`.** In the `lowerExpression` dispatch, add:

```dart
if (expr is SwitchExpression) {
  return _lowerSwitchExpression(expr);
}
```

**Step 2 — Implementation.** The recognized grammar is:

```
SwitchExpression(scrutinee, cases) where each case is:
  - ConstantPattern (literal: 'a', 42, true, null) → equality test
  - ObjectPattern(TypeName) with no fields → type test
  - ObjectPattern(TypeName, fields) with `:final name` shorthand fields → type test + LetNode bindings
  - WildcardPattern (`_`) → default case
```

Lower to a right-fold chain of `ConditionalNode`s, with the wildcard (or last case) as the terminal else. Pseudocode:

```dart
IrNode _lowerSwitchExpression(SwitchExpression expr) {
  final scrut = lowerExpression(expr.expression);
  // Hoist scrutinee into a LetNode so it's evaluated once.
  final scrutName = '__scrut__${_freshId()}';
  IrNode acc = _terminalElse(expr); // SizedBox or throw, see below
  for (final c in expr.cases.reversed) {
    final test = _lowerCaseTest(c.pattern, RefNode([scrutName]));
    final body = _lowerCaseBody(c.pattern, RefNode([scrutName]), lowerExpression(c.expression));
    if (test == null) {
      // Wildcard pattern: this is the default branch.
      acc = body;
    } else {
      acc = ConditionalNode(cond: test, then: body, els: acc);
    }
  }
  return LetNode(name: scrutName, value: scrut, body: acc);
}

IrNode? _lowerCaseTest(DartPattern p, IrNode scrutRef) {
  if (p is WildcardPattern || p is ConstantPattern && p.expression is NullLiteral && /*  fall-through */) {
    return null; // wildcard or null-fallthrough — caller handles
  }
  if (p is ConstantPattern) {
    return CompareOpNode(op: '==', left: scrutRef, right: lowerExpression(p.expression));
  }
  if (p is ObjectPattern) {
    final typeName = p.type.name.lexeme;
    return IsTypeNode(receiver: scrutRef, typeName: typeName);
  }
  throw InvalidScreenBodyError('Unsupported pattern: ${p.runtimeType}');
}

IrNode _lowerCaseBody(DartPattern p, IrNode scrutRef, IrNode body) {
  if (p is ObjectPattern && p.fields.isNotEmpty) {
    // Wrap each field binding in a LetNode around the body.
    var wrapped = body;
    for (final field in p.fields.reversed) {
      final getter = field.effectiveFieldName; // e.g. 'data' for `:final data`
      final bindName = field.pattern.boundVariableName; // same as getter for shorthand
      wrapped = LetNode(
        name: bindName,
        value: MemberAccessNode(target: scrutRef, name: getter),
        body: wrapped,
      );
    }
    return wrapped;
  }
  return body;
}
```

The exact analyzer AST names (`SwitchExpression`, `SwitchExpressionCase`, `ConstantPattern`, `ObjectPattern`, etc.) live in `package:analyzer/dart/ast/ast.dart`. Confirm the field accessors by reading the analyzer's source or a small probe test.

**Step 3 — Terminal else.** When no wildcard case is present, the chain must terminate somehow. Pick: throw `StateError('Non-exhaustive switch in @Screen body')` at runtime via a small runtime helper. Add `runtime.throwError(msg)` that the resolver can invoke via a new `ThrowNode` — or simpler, emit a literal `SizedBox.shrink()` widget as the default and document this as "non-exhaustive switches default to empty". Pick the SizedBox approach for simplicity; reject non-exhaustive switches in the lowerer with a diagnostic instead. Author must include `_ => fallback`.

**Step 4 — Record destructuring.** Recognize `VariableDeclarationStatement` whose variable is a `PatternVariableDeclaration` with a `RecordPattern`:

```dart
final (a, b) = vm.pair;
```

Lower to nested LetNodes:

```dart
LetNode('__rec0__', vm.pair,
  LetNode('a', MemberAccessNode(RefNode(['__rec0__']), r'$1'),
    LetNode('b', MemberAccessNode(RefNode(['__rec0__']), r'$2'),
      <rest of block>)))
```

This integrates with the LetNode-aware block-body lowerer (Feature 1) — record destructuring is just a special case of leading `final` declarations.

## Out of scope (deliberately)

- **Logical patterns** (`a || b`).
- **Guards** (`when` clauses).
- **`if-case` statements.**
- **Nested ObjectPattern fields** (`Loaded(items: [first, ...])`). Field shorthand `:final name` only — no nested matching.
- **Generic type instantiation in patterns.** `Loaded<int>()` matches by simple class name only; generic args are erased.
